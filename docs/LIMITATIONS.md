# 제한 사항과 차단된 기능

## BLOCKED: 비로그인 학생 응답 자동 저장

이 프로젝트는 GitHub Pages에서 실행되는 정적 웹앱이며 별도의 백엔드나 데이터베이스를 사용하지 않습니다. 비로그인 학생이 브라우저에서 작성한 응답을 같은 GitHub 저장소에 안전하게 자동 기록하려면 저장소 쓰기 권한이 있는 비밀값이 필요하지만, 그 값을 공개 정적 JavaScript에 포함하면 누구나 탈취할 수 있습니다.

따라서 현재 버전은 다음 흐름만 실제로 지원합니다.

1. 학생이 설문을 작성합니다.
2. 브라우저가 응답 JSON 파일을 생성해 학생 기기에 내려받습니다.
3. 학생이 강사가 안내한 안전한 경로로 파일을 전달합니다.
4. 강사는 결과 화면에서 여러 JSON 파일을 일괄 가져와 브라우저 안에서 분석합니다.

파일 다운로드는 제출이나 서버 저장이 아닙니다. UI도 이를 명확히 표시합니다.

## 관리자 GitHub 저장의 범위

관리자는 본인이 발급한 fine-grained PAT를 관리자 화면에 직접 입력해 `data` 브랜치의 설문 JSON만 저장할 수 있습니다.

- 토큰은 React 메모리 상태에만 존재합니다.
- URL, 로그, 소스, 빌드 산출물, localStorage, sessionStorage에 저장하지 않습니다.
- 토큰은 `hiphop5782/smart-survey`의 `Contents: Read and write` 최소 권한으로 제한해야 합니다.
- 신뢰할 수 있는 관리자 기기에서만 사용해야 합니다.
- 저장 후 GitHub Contents API로 같은 파일을 재조회하고 내용 일치를 확인합니다.

정적 브라우저 앱에서 입력하는 토큰은 완전한 보안 격리를 제공하지 않습니다. 의존성 또는 브라우저 확장 프로그램이 손상된 환경에서는 토큰이 노출될 수 있습니다.

## 공개 저장소와 개인정보

`data`는 별도 브랜치지만 저장소가 Public이면 브랜치 내용도 공개됩니다. 이름, 연락처, 이메일, 정확한 생년월일과 주관식 답변을 포함한 실제 학생 응답을 평문으로 커밋하지 않습니다. Git 이력은 파일 삭제만으로 완전히 지워지지 않습니다.

현재 `data` 브랜치에 둘 수 있는 데이터는 공개 설문 정의, 템플릿, 비식별 데모 데이터뿐입니다. 실제 응답 원본은 관리자의 로컬 브라우저에서만 가져와 분석합니다.

## 코드 퀴즈 정답

공개 설문 JSON은 모든 방문자가 읽을 수 있으므로 정답을 포함하지 않습니다. 결과 화면에서 강사가 정답을 선택하면 현재 브라우저 메모리에서만 정답률을 계산합니다.

## 수동 설정

DNS, GitHub Pages 활성화, 사용자 지정 도메인, 최초 `data` 브랜치 생성은 권한이 있는 저장소·도메인 관리자가 직접 수행해야 합니다.
